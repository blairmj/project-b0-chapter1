# PROJECT B-0 V4 — 함께 집으로

V1의 방·물리 퍼즐·공용 그림을 재사용한 독립 버전입니다. 시작 주소는 `https://blairmj.github.io/project-b0-chapter1/v4/`입니다. 공유 그림은 상위 `assets/`에서 읽고, 게임 코드와 저장 키는 V4 내부에 분리합니다.

## 이야기와 진행

나의 방에서 B-0와 공부 방법을 고르고 짧은 문제를 함께 해결합니다. 연구소가 개인화된 B-0를 회수하면, 태블릿의 제한된 연결을 통해 중앙관리실을 찾아갑니다. 출입 관리실 → 교육 실습실·물류 보관실 → 기록 보관실 → 유리 관찰실 → 거울 관찰실 → 계단 → 중앙관리실로 이어집니다.

게임 중 B-0는 태블릿 화면에 나타납니다. 기존에 몸으로 돕던 행동은 원격 보조팔·레일이 수행합니다. 복도에는 별도 B-0 몸을 표시하지 않고, 거울방에는 태블릿이 반사됩니다. 중앙관리실의 어두운 로봇 본체는 아직 연결되지 않은 도구입니다. 실제 몸의 첫 작동은 집으로 돌아온 엔딩에서 보여 줍니다.

## V4의 퍼즐 변경

- 첫 방의 비상 쪽지는 태블릿 케이스 수납칸에 있습니다.
- 교육 실습실의 계산 순서·중간 결과·최종 결과는 버튼으로 선택합니다.
- 기록 보관실에서는 같은 수업의 요약 5건과 원본 8건을 읽고 비교해야 비공개 회수 기록을 확인할 수 있습니다.
- 유리방에서 통과 전에 놓으면 문이 다시 잠깁니다. 문턱 통과나 이후 신호까지 유지해야 합니다.
- 거울방의 빛은 켜 둔 채 방향을 조절합니다. 기본 상태에서는 정답 단계와 다음 대상 강조를 숨깁니다.
- 중앙관리실에서는 빛의 경로를 맞춰 유지하고 연결 상태를 확인한 뒤, 원래 기록을 태블릿으로 복구해야 실제 제어 연결을 끊을 수 있습니다. 그 뒤 기존 잠금쇠·손잡이 협력이 이어집니다.

각 방의 `도움 요청`은 1~3단계로 깊어집니다. 3단계 도움에서는 거울방의 순차 안내와 강조가 켜집니다. 도움을 받았다는 이유로 실패 처리하거나 능력 점수를 낮추지 않습니다.

## 저장과 설문

저장 키는 모두 `project-b0-v4-`로 시작하며 V1의 저장·설문 초안을 읽거나 지우지 않습니다. 재시작은 V4 기록만 대상으로 합니다. 개인정보나 대화를 서버에 전송하지 않습니다.

`survey.html`은 `b0-post-v4-1.0` 전용 사후 설문입니다. 공통 자기평가 12개와 상황 판단 4개를 유지하고, 조작·재미와 구출 몰입·친밀감·선택 경험을 별도 경험 문항으로 다룹니다. 모든 질문은 선택이며 서술 응답도 필수가 아닙니다. JSON 파일을 저장해 전달하는 방식입니다.

`analysis.html`은 V4 응답만 읽습니다. 도움 수준, 원본 비교, 원래 기록 복구, 피지컬 귀환 상태와 기존 거울방 요약을 별도로 보여 줍니다. 학습·몰입·도움 사용을 하나의 역량 점수로 합산하지 않습니다. 사후 설문만으로 학습 향상이나 서사의 인과 효과를 주장하지 않습니다.

## 검사

`node v4/tests/v4-rescue.cjs`는 분리 저장, 여섯 방의 해법, 자료 비교, 조기 손잡이 해제, 실시간 빛, 계단 조건, 복구 후 연결 해제, 최종 협력, 설문과 CSV 연결을 검사합니다. `v4/tests/`의 나머지 회귀 검사는 재사용한 공간·물리·입력 기능을 확인합니다.
