# PROJECT B-0 V5 — 문 너머, 다음 방으로

플레이: https://blairmj.github.io/project-b0-chapter1/v5/

V1의 공개 파일과 저장을 유지하는 독립 버전입니다. 코드와 설문은 `v5/`, 그림·영상은 상위 `assets/`를 재사용합니다. V5의 모든 게임·설정·설문 저장 키는 `project-b0-v5-`로 시작합니다.

## 방의 연결

출입관리실 → 출입관리실 앞 복도 → 교육관찰실 → 거울관찰실 → 계단 문 → 2층 통제실 → B-0와 탈출.

첫 방을 나가면 복도 배경으로 전환된 뒤 출입카드 발견 알림이 뜹니다. 카드를 챙겨 교육관찰실 문으로 진행합니다. 이후에는 방의 출구로 다음 방에 바로 들어갑니다. 상단 왼쪽 드롭다운에서 이미 열린 방과 V5 설문으로 이동할 수 있으며, 아직 열지 않은 방은 잠겨 있습니다. 물류보관실·기록보관실·유리관찰실은 주 동선에서 제외합니다.

| 공간 | 할 일 | 획득물·다음 공간 |
| --- | --- | --- |
| 출입관리실 | B-0의 보관함과 쪽지를 찾아 도어락 열기 | 문 밖 복도에서 출입카드 발견·보조 배터리 → 교육관찰실 |
| 교육관찰실 | 큰 화면 앞 두 아이의 계산 순서 토론을 보고 순서·중간값·최종값을 버튼으로 고쳐 확인하기 | 기록 메모리·보조 배터리 → 거울관찰실 |
| 거울관찰실 | 실제 빛을 보며 두 거울을 조절해 출구 열기 | 반사판·보조 배터리 → 계단 문 |
| 계단 문 | 출입카드로 권한 확인, 메모리로 전원 복구, 반사판으로 빛 센서 작동 | 세 장치가 켜지면 2층 통제실 문 열림 |
| 2층 통제실 | 좌우로 회피하며 자동 발사로 액시엄에 6번 명중 | 해제 카드로 B-0의 반출 잠금 해제 후 즉시 탈출 |

수업 기록은 32.5초의 고정 구도 자막 영상입니다. 두 아이의 토론과 화면 속 풀이가 이어지며 카메라 이동·확대는 없습니다. 캐릭터 자체의 움직임과 음성은 없습니다. 플레이어는 일시정지·계속 보기·다시 보기를 한 버튼으로 제공하고, 수업 화면으로 돌아갈 수 있습니다.

진행 선택지가 있는 안내창·대화창에는 중복된 ‘닫기’를 추가하지 않습니다. 읽기 전용 창, 도어락·풀이·설정처럼 중간에 나와야 하는 입력창과 초기화 취소는 유지합니다.

## 슈팅 보스전

원래의 3D 통제실 배경과 B-0 한 대를 사용합니다. B-0는 늘 보이는 돔형 보호막 안에 있고, 반사판을 몸 앞에 듭니다. 마우스를 좌우로 움직이거나 화면을 손가락으로 끌면 B-0·보호막·반사판이 함께 이동합니다. 좌우 방향키·A/D도 지원합니다. 발사는 자동이며 기울기 버튼은 없습니다.

액시엄의 주황색 탄은 본체 중앙 한 곳에서 나오며 방향이 달라지고 주기적으로 부채꼴로 퍼집니다. 실제 탄이 보호막에 닿을 때만 HP가 줄어듭니다. 중앙 아래에서 쏜 반사탄은 명중하고, 옆으로 벗어난 탄은 빗나갑니다. 보호막 100, 액시엄 HP 180, 명중 피해 30입니다. 보조 배터리는 40을 회복하며 B 키로도 사용합니다.

전투 전 짧은 규칙 안내를 읽고 시작합니다. 규칙·메뉴·숨겨진 탭·포커스 이탈 동안에는 탄과 전투 시간이 멈춥니다. 승리 즉시 출구가 열리며 추가 손잡이 퍼즐은 없습니다.

## 저장과 조사

V1의 저장·설문을 읽거나 지우지 않습니다. V5 사후 설문 버전은 `b0-post-v5-1.1`입니다. 설문과 분석 페이지는 V5 폴더에서 열며 원자료는 서로 섞지 않습니다. 일부 기존 자기평가 문항을 재사용하지만 게임 구조가 달라졌으므로 V1과의 동등성이나 교육 효과가 검증된 척도로 취급하지 않습니다. 재미·조작·완료 과정과 관찰 행동을 먼저 확인하는 시제품입니다.

V5는 방 연결, 원본 단서 확인, 풀이 수정, 빛 실험과 전투 조작을 기록합니다. 보스전 성공이나 사후 자기평가만으로 AI 활용 능력 향상을 단정하지 않습니다.

## 검사

`v5/tests/`의 8개 검사 파일은 방별 획득 조건·직접 이동 콜백·계단 문 사용·재접속·V1 저장 분리·슈팅 충돌과 입력·설문 검증을 확인합니다. 실제 브라우저에서도 출입관리실에서 엔딩과 V5 설문까지 소리 없이 플레이했습니다. V1의 기존 27개 검사 파일도 통과했습니다.
