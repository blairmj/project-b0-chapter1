# PROJECT B-0 V5 — 문 너머, 다음 방으로

플레이: https://blairmj.github.io/project-b0-chapter1/v5/

V1의 공개 파일과 저장을 유지하는 독립 버전입니다. 코드와 설문은 `v5/`, 그림·영상은 상위 `assets/`를 재사용합니다. V5의 모든 게임·설정·설문 저장 키는 `project-b0-v5-`로 시작합니다.

## 방의 연결

출입관리실 → 출입관리실 앞 복도 → 교육관찰실 → 관제 기록실 → 거울관찰실 → 계단 문 → 2층 통제실 → B-0와 탈출.

첫 방을 나가면 복도 배경으로 전환된 뒤 출입카드 발견 알림이 뜹니다. 카드를 챙겨 교육관찰실 문으로 진행합니다. 이후에는 방의 출구로 다음 방에 바로 들어갑니다. 상단 왼쪽 드롭다운은 테스트용으로 모든 방을 바로 엽니다. 이때 별도 세션 저장소를 사용하고 앞 방의 준비물만 제공하며, 목적지 퍼즐은 직접 테스트합니다. 메뉴의 ‘일반 모험으로 돌아가기’로 기존 진행에 복귀할 수 있습니다. 물류보관실·유리관찰실은 주 동선에서 제외하고, 기존 기록보관실의 3D 공간은 관제 기록실로 재사용합니다.

| 공간 | 할 일 | 획득물·다음 공간 |
| --- | --- | --- |
| 출입관리실 | 벽의 네 조건을 비교해 서로 다른 세 자리 비밀번호 찾기; B-0가 학생의 가설을 질문으로 검토 | 문 밖 복도에서 출입카드 발견·보조 배터리 → 교육관찰실 |

| 계단 문 | 출입카드로 권한 확인, 메모리로 전원 복구, 반사판으로 빛 센서 작동 | 세 장치가 켜지면 2층 통제실 문 열림 |
| 2층 통제실 | 좌우로 회피하며 자동 발사로 액시엄에 6번 명중 | 해제 카드로 B-0의 반출 잠금 해제 후 즉시 탈출 |

수업 기록은 32.5초의 고정 구도 자막 영상입니다. 두 아이의 토론과 화면 속 풀이가 이어지며 카메라 이동·확대는 없습니다. 캐릭터 자체의 움직임과 음성은 없습니다. 플레이어는 일시정지·계속 보기·다시 보기를 한 버튼으로 제공하고, 수업 화면으로 돌아갈 수 있습니다.

일반 B-0 대화는 ‘다음’ 하나로 읽고 끝냅니다. 질문 목록과 요청 메뉴를 대화에 붙이지 않으며, 필수 행동 하나만 마지막 대화 뒤에 이어집니다. 퍼즐의 숫자 선택·자유 지시는 별도 퍼즐 화면에 둡니다. 진행 선택지가 있는 안내창에는 중복된 ‘닫기’를 추가하지 않습니다. 읽기 전용 창, 도어락·풀이·설정처럼 중간에 나와야 하는 입력창과 초기화 취소는 유지합니다.

## 관제 기록실 · 최적 경로

V5의 `chapter3.js`/`chapter3-model.js`에서 이전 배치도·폐쇄 통로·보관장 이동 판정을 교체했습니다. 날짜 조작이나 동쪽 통로 점검 날짜 설정은 기존 이 저장소에서 발견되지 않았습니다. 다른 버전과 AXIOM 보스전은 유지합니다. 기존 벽·바닥·서버·단말기·B-0·문 그래픽을 재사용합니다.

경로는 방향이 있으며 구간 시간은 4/3/2/6/5/4/5/3분입니다. 가능한 완주 경로는 10, 11, 13, 13분입니다. 실제 이동 조건은 ‘인증 게이트 필수, 12분 이내, 조건을 만족하는 최단 경로’이며 유일한 최적 경로는 출발 → 서쪽 복도 → 인증 게이트 → 목적지(11분)입니다.

처음 B-0는 인증을 필수로 넣지 않아 10분 경로를 추천합니다. 질문은 계산 근거를 보여 주고, 학생의 조건 수정은 B-0의 판단 기준과 학습 로그를 갱신합니다. 수정 후에는 경로를 다시 검증해야 이동을 실행합니다. 성공은 B-0의 이동과 실제 3D 문 개방으로 표현합니다. 제한 12분은 경로 비용이며 현실의 대기 시간을 뜻하지 않습니다.

자유 입력과 선택형 문장을 함께 제공합니다. 정확한 한 문장/비밀번호로만 진행하지 않으며, ‘인증을 꼭 거쳐’, ‘게이트가 빠졌잖아’, ‘신원 확인하는 곳을 반드시 지나’, 실패 확인 뒤 ‘그 조건도 반영해’ 등의 표현을 처리합니다. 현재 자연어 처리는 **이 경로 퍼즐 범위의 규칙 기반 의미 분류**입니다. 외부 LLM 연결이나 신경망 학습은 없으며, 이해하지 못한 말은 조건을 다시 물어봅니다. 실제 학생들의 다양한 표현은 추가 수집·검토가 필요합니다.

저장 키는 `project-b0-v5-control-route-v2`입니다. 추천, 수정 기준, 검증, 대화, 이동과 학습 로그를 저장합니다. 도중 새로고침하면 검증 내용을 유지하되 미완료 이동을 자동 성공 처리하지 않습니다. 이 방 재시작 또는 새 모험 시작은 관련 상태를 초기화합니다. 예전 V5의 후반 저장은 도구를 유지하면서 새 관제 기록실로 연결하고, 이미 B-0 구출을 끝낸 저장의 엔딩은 유지합니다.

## 출입관리실 · 세 자리 추론

서로 다른 1~9 세 숫자, 첫째=셋째×2, 둘째+셋째=7, 첫째+둘째=9입니다. 정답은 452입니다. B-0는 정답을 제시하지 않고 학생이 고른 첫째/셋째/둘째와 마지막 합을 질문합니다. 6→3→4→10은 마지막 조건과 충돌하며 재검토할 수 있습니다. 숫자 버튼만으로 진행하고 답안을 자동 입력하지 않습니다.

## 테스트 이동과 저장 분리

드롭다운 이동은 `project-b0-v5-test:` 접두사의 sessionStorage를 사용합니다. 일반 모험 localStorage, V1 저장과 설문은 변경하지 않습니다. 목적지 앞방만 준비하고 해당 방은 풀지 않습니다. 테스트 도중의 기준 수정이나 도구 사용은 테스트 저장에만 남습니다. 일반 모험의 출구는 원래의 퍼즐 완료 조건을 유지합니다.

## 슈팅 보스전

원래의 3D 통제실 배경과 B-0 한 대를 사용합니다. B-0는 늘 보이는 돔형 보호막 안에 있고, 반사판을 몸 앞에 듭니다. 마우스를 좌우로 움직이거나 화면을 손가락으로 끌면 B-0·보호막·반사판이 함께 이동합니다. 좌우 방향키·A/D도 지원합니다. 발사는 자동이며 기울기 버튼은 없습니다.

액시엄의 주황색 탄은 본체 중앙 한 곳에서 나오며 방향이 달라지고 주기적으로 부채꼴로 퍼집니다. 실제 탄이 보호막에 닿을 때만 HP가 줄어듭니다. 중앙 아래에서 쏜 반사탄은 명중하고, 옆으로 벗어난 탄은 빗나갑니다. 보호막 100, 액시엄 HP 180, 명중 피해 30입니다. 보조 배터리는 40을 회복하며 B 키로도 사용합니다.

전투 전 짧은 규칙 안내를 읽고 시작합니다. 규칙·메뉴·숨겨진 탭·포커스 이탈 동안에는 탄과 전투 시간이 멈춥니다. 승리 즉시 출구가 열리며 추가 손잡이 퍼즐은 없습니다.

## 저장과 조사

V1의 저장·설문을 읽거나 지우지 않습니다. V5 사후 설문 버전은 `b0-post-v5-1.1`입니다. 설문과 분석 페이지는 V5 폴더에서 열며 원자료는 서로 섞지 않습니다. 일부 기존 자기평가 문항을 재사용하지만 게임 구조가 달라졌으므로 V1과의 동등성이나 교육 효과가 검증된 척도로 취급하지 않습니다. 재미·조작·완료 과정과 관찰 행동을 먼저 확인하는 시제품입니다.

V5는 방 연결, 원본 단서 확인, 풀이 수정, 빛 실험과 전투 조작을 기록합니다. 보스전 성공이나 사후 자기평가만으로 AI 활용 능력 향상을 단정하지 않습니다.

## 검사

`v5/tests/`의 12개 검사 파일은 세 자리 추론·다음 단일 대화·유효/무효 경로·자연어 수정/부정/문맥·독립된 재검증·방별 획득 조건·직접 이동·초기화/저장·격리 테스트 이동·슈팅·설문을 확인합니다. 이번 변경은 브라우저에서 세 자리 오답·정답, 다음 단일 대화, 10분/13분 이동 차단, 자연어 피드백, 11분 재검증과 실제 문 개방, 거울관찰실 연결, 초기화, 통제실 바로 이동과 일반 모험 복귀를 소리 없이 확인했습니다. 보스전·설문 회귀 검사도 통과했습니다. 변경한 파일은 V5 내부에 한정합니다.
