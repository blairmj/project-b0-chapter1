# PROJECT B-0 v3 · B-0에게 지시하기

[v3 게임](https://blairmj.github.io/project-b0-chapter1/v3/) · [기존 v1](https://blairmj.github.io/project-b0-chapter1/)

AI 로봇 B-0에게 적절한 명령을 내려 연구소를 탈출하는 1인칭 퍼즐 어드벤처.

- 플레이어: 단서 관찰, 대상·행동·조건 결정, 실행 결과 검증, 잘못된 지시 수정.
- B-0: 지시한 물건 조사, 계산 실행, 상자 운반·쌓기, 기록 장치 조작, 장치 유지.
- 지시창: 확인한 대상 → 행동 → 필요한 목적지·계산 규칙·유지 조건을 조합. 정답 명령 자동 선택 없음.
- 다른 대상에 맞지 않는 행동은 실행하지 않고 이유 설명. 잘못된 계산 규칙은 실제 오답 과정으로 표시.

| 공간 | B-0에게 지시하는 일 | 플레이어가 확인하는 것 |
| --- | --- | --- |
| 출입 관리실 | 보관함 열기, 발견한 번호 입력, 문 열기 | 쪽지와 도어락의 정보 |
| 교육 실습실 | 지정한 규칙으로 계산, 규칙 변경 후 재실행, 메모리 전달 | 중간 계산 과정과 오류의 원인 |
| 물류 보관실 | 물건·목적지 지정 운반, 다른 상자 위에 쌓기, 학생 받쳐 올리기 | 창문 너머와 실제 상자 배치·높이 |
| 기록 보관실 | 컴퓨터 전원·메모리 연결, 혼자 또는 함께 보관장 밀기 | 오래된 기록과 실제 출구의 차이 |
| 유리 관찰실 | 손잡이의 모양·방향·유지 조건 지정 | 양쪽 장치 반응과 열린 문 |
| 중앙관리실 | 몸 상태 확인, 학생 들어 올리기, 지정한 손잡이 유지·해제 | 원격 제어 연결과 실제 잠금쇠 |

상자에 올라서기, 창틀에서 B-0의 손 잡기, 유리벽 이쪽 손잡이, 최종 문의 동시 조작은 플레이어가 직접 수행. B-0와 서로 다른 위치에서 협동해야 하는 상황 유지.

유리 관찰실에서 정한 유지 약속을 별도 지시 수첩에 저장. 마지막 관문에서 같은 약속을 다시 사용 가능. 실제 모델 학습·생성형 AI 호출은 사용하지 않는 규칙 기반 프로토타입.

기록 메모리는 교육 실습실에서 획득해야 하며, 소지하지 않으면 기록 보관실 입장 불가. 계단 열쇠와 2층 진입 조건 유지.

## 버전과 저장

- 루트의 v1 실행 코드·저장 데이터 유지.
- 기존 별도 실험용 `PROJECT_B0_v2` 폴더 유지.
- v3 실행 코드는 이 폴더에 분리. 기존 이미지·영상·폰트는 부모 `assets`에서 공유.
- v3 진행·아이템·지시 수첩은 `project-b0-v3-` 키로 별도 저장. 새 게임은 v3 데이터만 초기화.
- 임시 차시·위치 이동은 검토용 기능. 일반 진행 검토는 처음부터 시작으로 진행.

## 참고

- 공통 지시 UI: `commands.js`, `commands.css`.
- 지시 규칙·계산·유지 조건: `command-model.js`.
- 방별 실행과 B-0 이동은 각 방 컨트롤러에서 처리.
