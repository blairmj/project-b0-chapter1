# PROJECT B-0 · 1차시: 흐릿한 기록

[GitHub Pages에서 플레이](https://blairmj.github.io/project-b0-chapter1/)

## 플레이

- 자유 이동 → 가까운 물건 조사 → 단서 수집·조합 → 문 앞 잠금 퍼즐 → 복도로 탈출.
- 방 전체에는 물건 이름·정답 표시·다음 행동 안내를 상시 노출하지 않음.
- 물건 또는 바닥을 누르면 학생과 B-0가 이동. 가까이 도착하면 ‘살펴보기’ 표시.
- 키보드: Tab으로 물건 선택 후 Enter, 또는 방 영역에서 방향키로 이동.
- 조사 시 확대 화면. 수납장 서랍 열기, 기록 카드 뒤집기, 액자 살펴보기.
- 문을 먼저 조사해도 됨. 단서를 찾는 순서와 B-0 대화 여부를 강제하지 않음.
- 단서 수첩은 발견한 내용만 보관. 문 앞에서도 펼쳐 볼 수 있음.
- 힌트는 메뉴에서 요청할 때만 단계적으로 제공.

## 퍼즐과 교육

- 수납장: ○=2, ★=6 기호표.
- 액자: ★ → ○ → △ 읽는 순서.
- 책상: △의 숫자가 번진 카드. 뒷면 원본은 3.
- 잠금 번호: 623. 오답은 자유롭게 재시도하며 방으로 돌아가 재조사 가능.
- B-0는 번진 앞면을 8로 추정하고 불확실성을 명시. 학생이 원본을 보여 주면 3으로 수정.
- AI의 추정과 확인된 사실 구별, 원자료와 비교해 결과 검증, 여러 단서의 관계 추론.
- B-0와 대화하지 않아도 탈출 가능. 교사는 해법 비교 시간에 AI 판독과 검증을 함께 다룸.
- 초등 5–6학년. 40분 운영 예: 도입 5 / 탐색·짝 토의 15 / 해법·AI 판독 비교 10 / 단서 만들기·정리 10분.
- 게임 자체는 단일 퍼즐 시제품. 40분 전체 수업 또는 4차시 전체 구현이 아님.
- 탈출 후 복도에서 AXIOM의 B-0 복귀 명령. 다음 방은 미구현.

## 구현

- index.html: 기본 진입점. preview-v2.html: 같은 버전의 확인용 진입점.
- escape.js: 탐색·물건 조사·단서·잠금·로컬 저장.
- escape.css: 단순한 방 구조와 물건 SVG, 이동, 확대 조사 UI.
- 기존 학생과 B-0 PNG 애셋 재사용. 복잡한 배경 PNG와 장치 아틀라스는 새 방에서 사용하지 않음.
- lesson1.js, lesson1.css, game.js, style.css는 이전 구현 보관.
- 기존 프롤로그 MP4는 시작 화면에서 선택 재생.
- 음성 대사 없음. 짧은 발견·잠금 효과음만 사용. 카메라 흔들림 없음.
- 정적 HTML/CSS/JS. 서버 API, 실제 생성형 AI 호출, API 키, 빌드 과정 없음.
- 로컬 서버: python -m http.server 8000 실행 후 http://localhost:8000.
