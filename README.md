# PROJECT B-0 · 연구소 탈출

**초등 고학년을 위한 AI 교육용 1인칭 퍼즐 어드벤처.**

모르는 것이 많은 AI 로봇 B-0와 함께 연구소를 탐색하고, 묻고 가르치고 확인하며 탈출하는 웹게임입니다.

[게임 플레이](https://blairmj.github.io/project-b0-chapter1/) · [소스코드](https://github.com/blairmj/project-b0-chapter1)

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 초등학교 5~6학년 |
| 장르 | 스토리 기반 퍼즐 어드벤처 / 방탈출 / 게임기반학습 |
| 시점 | 학생의 눈으로 보는 1인칭 |
| 핵심 경험 | 직접 탐색 → 단서 확인 → B-0에게 구체적으로 부탁 → 조작 → 결과 검증 |
| 교육 주제 | AI의 한계 이해, 명확한 지시, 역할 분담, 오류 수정, 정보와 결과 검증, 사람의 판단 |
| 실행 환경 | PC·태블릿의 웹 브라우저, 세로 화면 중심 |
| 현재 범위 | 4차시 공간과 엔딩까지 연결된 플레이 가능한 프로토타입 |

### 이야기

- 폐쇄된 AI 교육 연구소에서 깨어난 소년과 교육용 AI 로봇 B-0의 만남.
- 스스로 관찰하고, B-0가 모르는 것을 알려 주고, 서로의 역할을 나누며 연구소 탐색.
- 교육 실습실의 수업 기록과 기록 보관실의 비밀 일지에서 연구소의 운영 방식 발견.
- 중앙관리 AI AXIOM의 B-0 회수·초기화 명령에 맞서 함께 탈출할 방법 탐색.

## 2. 차시와 공간

| 차시 | 주요 공간 | 플레이 활동 | 연결되는 교육 내용 |
| --- | --- | --- | --- |
| 1 | 출입 관리실 | 물건과 B-0를 조사하고, 발견한 쪽지로 출입문 개방 | AI도 확인하지 않은 정보는 모를 수 있음. 대상과 질문을 구체적으로 정하기 |
| 2 | 교육 실습실·물류 보관실 | 수업 속 틀린 풀이 수정·검증, 기록 메모리 획득. 상자 배치와 B-0의 도움으로 탈출 | 필요한 설명·부분 검산 요청, 오류 수정, 사람과 AI의 역할 분담 |
| 3 | 기록 보관실·유리 관찰실 | 메모리를 컴퓨터에 연결해 비밀 일지 발견. 오래된 배치와 실제 방 비교, 유리벽 양쪽에서 협동 조작 | 정보의 근거·현재 상태 확인, 명확한 대상·동작·종료 조건 전달 |
| 4 | 2층 중앙관리실 | B-0의 상태와 제어 연결을 확인하고, 잠금장치를 협동 조작해 출구 개방 | 앞서 익힌 협력 방식 종합, 실제 결과 검증, AI 사용에서 사람의 판단 |

- 교육 실습실은 2차시 권역의 추가 공간으로, 별도 차시 번호 없이 연결.
- 1층 방은 복도에서 선택해 탐색. 차단 구역과 계단은 해당 통로·열쇠 조건에 따라 접근.
- 교육 실습실에서 기록 메모리를 획득해야 기록 보관실에 입장 가능. 컴퓨터에 연결하면 비밀 일지 파일 발견 가능.
- 기록 보관실은 하드디스크를 보관한 서버 랙과 열람 컴퓨터로 구성. 빈 바닥을 클릭해 이동하고 물건을 눌러 조사.
- 유리 관찰실 너머에서 열쇠 획득 → 계단 차단 해제 → 2층 중앙관리실 진입.

## 3. 조작 방법

| 조작 | 동작 |
| --- | --- |
| 마우스 왼쪽 버튼·터치 드래그 | 방과 복도 둘러보기 |
| 물건 클릭·탭 | 조사하거나 가능한 행동 선택 |
| 복도 바닥 클릭·탭 | 선택한 위치로 이동 |
| 하단 방향 화살표 / 방향키·WASD | 복도 이동·좌우 시선 전환 |
| 움직일 수 있는 물건 드래그 | 상자 이동, 손잡이·잠금쇠·연결 단자 조작. 대상별 버튼 조작도 지원 |
| B-0에게 말하기 | 현재 상황에 맞는 질문·협력 요청 |
| 처음 위치로 | 현재 공간의 시점과 배율 초기화 |
| 마우스 휠 / 상단 −·+ | 화면 확대·축소. 팝업 안에서는 내용 스크롤 |
| 메뉴 | 지도·소지품·사용법·기록 보기·시작 화면 |

- 출입 관리실은 파노라마를 둘러보는 방식. 복도는 바닥을 눌러 직접 걷는 방식.
- 빈 책상 조사는 시점을 유지. 복도의 일반적인 자동 이동·회전은 드래그로 시선 조작 전환 가능.
- 문 통과와 계단 이동은 별도의 이동 연출 사용.
- 자세한 조작은 게임 안의 **메뉴 → 사용법**에서 확인.

### B-0 호칭과 유리 관찰실의 부탁 구성

- 아이와 B-0의 대화는 방 화면 아래 말풍선에서 읽습니다. 질문·부탁과 교육 실습실의 말로 하는 도움도 같은 영역을 쓰며, 메뉴·기록·설정·쪽지·풀이·그림 자료는 팝업에서 확인합니다.
- **메뉴 → B-0 설정**에서 ‘주인님·친구·탐험가’ 중 고르거나 원하는 호칭을 1~20자로 직접 입력해 저장합니다. 이 브라우저에 설정을 저장하고 다음 대화부터 적용합니다. 게임 진행 초기화와는 별개입니다.
- 유리 관찰실에서는 실제 손잡이를 가리킨 다음 움직임을 드래그로 보여 주거나 방향 버튼으로 고릅니다. ‘한 번 움직이고 놓기·문이 열리면 놓기·내가 문턱을 지나면 놓기·내가 신호하면 놓기’ 중 종료 사건을 직접 정합니다. 타이핑은 필요하지 않습니다.
- B-0의 확인 문장을 보고 **이 부탁 보내기**를 누릅니다. 처음에는 방향·종료 조건이 선택되어 있지 않으며, 잘못 가리킨 대상이나 위쪽 움직임도 실제 장치 반응으로 확인할 수 있습니다.
- 문이 열리는 사건, 플레이어의 실제 문턱 통과, 명시적인 신호를 구분합니다. 신호 조건에서는 문이 열려도 B-0가 계속 기다립니다. 진행을 막는 부탁은 ‘부탁 멈추기’나 새 부탁으로 바꿀 수 있습니다.
- 관찰실 저장에 지시 초안의 수정, 실행 당시 대상·방향·종료 조건, 이후 조사와 종료 사건을 시각·요청 번호와 함께 남깁니다. 이 기록은 현재 브라우저의 진행 저장 안에 보관합니다.

### 임시 검토 기능

- **왼쪽 상단 위치 드롭다운:** 1·2층 복도와 각 방으로 바로 이동.
- **차시 앞으로 / 차시 끝으로:** 차시 시작 또는 마무리 상태로 이동하는 개발 확인용 기능.
- 위치 드롭다운은 소지품·퍼즐 진행을 유지. 차시 이동 버튼은 진행을 초기화하거나 완료 상태를 만들 수 있음.
- 임시 2층 이동은 실제 열쇠 획득·계단 해제를 대신 기록하지 않음.
- 정상적인 플레이 흐름 검토는 임시 기능을 사용하지 않고 **처음부터 시작**으로 진행.

## 4. 플레이와 저장

### 플레이 후 설문과 교사용 분석

- 엔딩의 **모험 돌아보기 · 설문**에서 [학생 설문](https://blairmj.github.io/project-b0-chapter1/survey.html)으로 이동합니다. 직접 접속도 가능합니다.
- 자기평가 12문항, 상황 판단 4문항, 플레이 경험 4문항, 선택 서술형 3문항으로 구성합니다. `b0-post-1.0`은 기본판 목표에 맞춘 시범 도구이며 검증된 표준 척도가 아닙니다.
- 학생은 마지막 단계에서 JSON 응답을 저장해 교사가 정한 경로로 전달합니다. 정적 GitHub Pages이므로 자동 전송·중앙 수집은 하지 않습니다. 작성 중 응답 1건은 해당 브라우저에만 자동 저장합니다.
- [교사용 분석](https://blairmj.github.io/project-b0-chapter1/analysis.html)은 여러 JSON 응답을 탭 안에서 불러와 문항군 평균·SD·중앙값, 문항별 분포·결측, 상황별 정답률을 표시합니다. 서버 업로드는 없습니다.
- 원자료·요약·서술형 코딩 CSV와 재개용 분석 묶음 JSON을 저장할 수 있습니다. 서술형은 교사가 직접 코딩하며, 분석 묶음은 불러온 모든 응답과 코딩을 보관합니다. 미리보기 응답은 기본 분석에서 제외합니다.
- [분석 방법](https://blairmj.github.io/project-b0-chapter1/analysis-methods.html)에 문항 ID, 채점, 결측 처리, 수집 절차, 코딩 기준, 사후 자료 해석의 한계와 후속 효과 검증 설계를 정리했습니다.
- 검사: `node tests/survey-model.cjs`. 설문과 분석 화면은 빌드·설치 없이 실행됩니다.

[GitHub Pages에서 플레이](https://blairmj.github.io/project-b0-chapter1/)

시작 화면에서 **처음부터 시작** 또는 **이어하기** 선택.

### 저장 방식

- 게임 진행은 브라우저에 자동 저장.
- 방별 퍼즐, 소지품, 복도 위치, 열쇠·계단, 정전·비상 조명 상태 저장.
- 방을 옮기거나 **처음 위치로**를 눌러도 정전·퍼즐 상태 유지.
- **처음부터 시작**은 해당 실행 환경의 게임 진행 초기화. 브라우저·기기 간 저장 동기화는 미구현.

### 렌더링 구조

WebGL 배경을 공통으로 사용하며, 공간 표현과 이동 방식은 다음과 같이 구성.

| 공간 | 공간 표현 | 이동 방식 |
| --- | --- | --- |
| 출입 관리실 | 360도 파노라마 이미지 투영 | 시선 회전과 물건 조사 중심 |
| 복도 | 벽·문·계단을 입체 도형으로 구성 | 바닥 클릭으로 걷기, 시선 회전 |
| 나머지 방 | WebGL 입체 배경과 CSS 3D 퍼즐 물체 조합 | 물건에 접근, 상자에 오르기 등 상황별 이동 |

- **B-0:** 이미지·SVG·평면 스프라이트 기반 표현. 눈·입 움직임과 상황별 자세를 조합.
- **실습실 영상:** 생성 일러스트에 느린 줌을 적용한 12초 무음 컷 영상. 재생·정지·되감기·텍스트 자막 지원.
- **AI 동작:** 정해진 게임 규칙과 대화 분기. 실제 생성형 AI 호출·음성 인식·얼굴 인식·모델 학습은 사용하지 않음.

### 거울 관찰실과 휴대용 반사판

유리 관찰실은 기존 공간으로 유지합니다. 새 거울 관찰실은 그 뒤 1층 복도의 별도 문과 상단 위치 이동 메뉴에서 들어갑니다. 반사되는 벽·바닥·천장, 실제 B-0의 반사상, 한 번의 관찰대 회전, 두 반사판의 광선 추적을 WebGL로 표시합니다. WebGL을 사용할 수 없으면 동일한 규칙의 배치도로 전환합니다. 감소된 동작 설정에서는 회전 연출을 생략합니다.

반사판의 각도는 버튼이나 슬라이더로 선택하며 타이핑하지 않습니다. 좁은 수광 장치의 앞쪽 개구로 빛이 들어와야 문이 열립니다. 표준 각도 일치 표시와 실제 수광·출구 상태는 따로 보여 줍니다. 시험 전 예상과 장치 관찰, 각도 변경, 실제 시험 결과를 저장합니다. 성공 뒤 A의 휴대용 반사판을 챙겨야 퇴장할 수 있습니다.

새로 시작하는 모험에서는 광학 교정을 마치고 반사판을 챙긴 뒤 계단실 열쇠를 얻습니다. 이전 버전의 모험과 완료 기록은 기존 진행을 유지합니다. 반사판을 가진 상태로 중앙관리실의 회수 제어에 맞서면 다른 배치의 광학 경로를 찾아 유지하고, B-0가 실제 제어 연결을 끊도록 부탁합니다. 이후 기존 상부 잠금쇠·손잡이 협력·함께 나가는 결말로 이어집니다. 재접속은 반사판을 물리적으로 유지하던 상태를 해제합니다. 이미 최종 방을 완료한 기록으로 새 공략을 다시 플레이하려면 반사판 획득 뒤 중앙관리실 메뉴의 현재 공간 다시 시작을 사용합니다.

새 모듈은 `reflection-model.js`, `reflection-view.js`, `reflection-room.js`, `reflection-room.css`, `optical-boss.css`입니다. 저장 키 `project-b0-reflection-v1`과 익명 플레이 ID `project-b0-play-id-v1`은 이 브라우저에만 저장합니다. 설문 1.1은 필요한 행동 요약만 응답 파일에 함께 담으며, 분석은 1.0/1.1을 구분합니다.

거울 관찰실 입장 시 목표와 걷기·둘러보기·거울 조작 방법을 안내창으로 표시합니다. 바닥 클릭, ↑↓/W/S, 화면 이동 버튼으로 걷고 A/D로 옆걸음을 합니다. 이동은 실제 방 경계와 거울·기계·B-0의 위치를 따라 제한하며, 물건 가까이 가기도 걸어서 이동합니다. 방 안내 버튼으로 설명을 다시 열 수 있습니다. 학생 화면에서는 거울 A/B·빛 기계·빛 받는 곳과 왼쪽/오른쪽 몇 칸 표현을 사용합니다.
