# PROJECT B-0 · 연구소 탈출

## 복도 드래그와 빈 책상 입력

- 복도 둘러보기: 드래그가 시작되면 포인터를 캡처하여 상단바·하단바 경계 밖으로 끌어도 회전 유지. 포인터 해제·취소·포커스 이탈 때 캡처 정리.
- 일반 걷기·방향 화살표·처음 위치로의 자동 카메라 동작은 드래그가 넘겨받을 수 있음. 문 통과와 계단 이동은 별도의 보호된 카메라 경로 유지.
- 드래그 뒤 합성 클릭을 시간차와 관계없이 구분하여 문 선택·바닥 이동 오작동 방지. 다음 실제 클릭과 메뉴·화살표 조작은 정상 처리.
- 교육 실습실의 빈 책상은 시점을 유지하며 조사. 모든 책상을 동일한 좌표로 보던 자동 접근 제거, 이전 자동 접근도 책상 조사 시 취소. 영상·풀이 단말기의 접근과 직접 드래그는 유지.
- 검사: `tests/lab-navigation-input.cjs`, `tests/education-input.cjs` 및 실제 마우스 드래그·책상 클릭 검증.

## 임시 위치 이동과 연결 검증

- 왼쪽 상단 위치 표시를 개발 확인용 드롭다운으로 교체. 1층 복도·출입 관리실·교육 실습실·물류 보관실·기록 보관실·유리 관찰실·2층 복도·중앙관리실로 이동.
- 임시 이동은 진행 중인 문 통과·카메라 동작·팝업을 정리하고 선택한 공간을 렌더링. 2층 검토 접근은 실제 열쇠나 계단 해제 기록을 지급하지 않으며, 새 게임에서 검토 모드 초기화.
- 완료한 물류 보관실 재방문 시 마무리 화면 대신 방을 열고 상자 위치·완료 기록 유지. 유리 관찰실에서 기록 보관실로 이동 시 별도 거울방 진행을 보존하면서 기록실 표시. 첫 방 재방문과 새로고침도 방 보기 유지.
- 실습실 메모리를 가진 경우 기록 보관실 입장 대사를 메모리 열람 목적과 연결. 실습실 사용법은 영상·풀이 단말기 조작으로 수정.
- 실제 새 진행: 첫 만남 → 관리 쪽지와 출입문 → 정전 복도 → 실습실 오답 수정·메모리 → 물류 보관실 상자·B-0 구조 → 기록실 컴퓨터·비밀 일지 → 방송 → 숨은 문으로 복도. 이 경로에서는 임시 이동·차시 건너뛰기를 사용하지 않음.
- 지도·영상·풀이·파일·일지·소지품 팝업을 닫고 조작 재개 검증. 별도 검토에서 드롭다운 8곳 왕복, 저장 유지, 320px 상단 스크롤 없음 확인.

## 교육 실습실과 비밀 교육 기록

- 출입 관리실의 관찰창 너머 교실을 별도 탐색 공간으로 추가. 1층 출입 구역에서 물류 보관실 맞은편 문으로 입장, 같은 문으로 복도에 복귀.
- 기존 방과 같은 WebGL 벽·바닥·천장, 금속 질감, B-0 SVG 표정·입 움직임, 공통 메뉴·카메라·문 통과 연출 사용.
- 12초 H.264 수업 기록 영상: 좌절한 두 아이의 생성 일러스트에 느린 줌 적용. 음성·캐릭터 모션 없는 컷 애니메이션이며 재생·정지·되감기·한국어 자막 지원.
- `24 ÷ 3 × 2`의 틀린 풀이 관찰 → 계산 순서와 중간값·최종 답 직접 수정 → 필요할 때 B-0에 순서 설명·묶음 그림·부분 검산 요청 → 수정 결과 검증 → 기록 메모리 획득.
- 메모리 소지 여부를 차시와 방 사이에 저장. 복구 전 획득·중복 획득 방지. 전체 새 게임에서 초기화, 기존 저장과 퍼즐 진행은 유지.
- 기록 보관실: 컴퓨터 전원 → 메모리 연결 → 파일 목록 → 복구된 기록 → 비공개 교육 운영 일지. 연결 전에는 해당 파일을 표시하지 않음.
- 일지를 닫으면 소년의 반박과 AXIOM 방송 대사 연결. 열람 차단 후 메모리 분리·소지품 복귀, 기존 보관장·숨은 문 퍼즐 계속 조작 가능. 중앙관리실 구현은 유지.
- 상단 임시 버튼 글자·폭 축소, 단일 행 유지. 좁은 세로 화면용 크기 조절로 상단 가로 스크롤 제거.
- `education-model.js`, `education-room.js`, `education-room.css`, `tests/education-story.cjs`. 영상 생성 출처와 방식: `assets/education-recording-manifest-v1.json`.

## 나머지 방의 WebGL 전환

- 물류 보관실·기록 보관실·유리 관찰실·중앙관리실의 벽·바닥·천장을 실제 WebGL 입체 면으로 렌더링. 기존 방별 금속 텍스처와 색감 재사용.
- 같은 카메라 행렬을 공유하는 혼합 렌더링. 퍼즐 물체·유리·B-0·1인칭 손은 기존 CSS 3D/SVG 레이어 유지. 보관장이 문과 B-0를 가리는 순서, 드래그·쌓기·올라서기·표정·구조 동작 유지.
- `room-webgl.js`가 기존 장면의 실제 치수와 변환을 읽으므로 퍼즐 좌표·충돌 규칙·저장 형식 변경 없음. 카메라 변경과 같은 프레임에 GPU 화면 갱신, 정지 화면의 중복 그리기 생략. DPR 최대 1.5, 긴 축 최대 1600px로 렌더링 비용 제한.
- WebGL 또는 텍스처 로딩 실패 시 기존 CSS 배경으로 복귀. 방 이동·재시작·임시 차시 이동 시 이전 GPU 자원 해제.
- 복도 입장 선택 → 문 쪽으로 접근 → 짧은 암전 → 방으로 진입. 기록 보관실·중앙관리실에 복도에서 들어오면 소개 대사를 실제 방 안에서 진행.
- 메뉴·시작 화면·임시 이동으로 진행 중 입장을 취소할 수 있으며, 복도에서 새로고침해도 도달한 복도 위치 복원.
- 메뉴로 잠시 방을 나올 때는 해당 문 앞에 복귀하며 클리어를 부여하지 않음. 보관실 창문·기록실 숨은 출구 등 퍼즐을 푼 뒤의 별도 출구는 유지. 유리 관찰실에서도 해당 복도 문으로 되돌아갈 수 있음.
- 기록 보관실의 자동 시점 이동 중에도 새 물체 선택·수동 회전으로 전환 가능. 방과 복도의 왕복에 동일한 짧은 화면 전환 사용.
- 반복 왕복 시 장면·오디오를 한 번만 정리하도록 모든 차시와 복도 종료 처리를 보호. 엔딩 후 재입장·복도 복귀에서도 닫힌 AudioContext를 다시 종료하지 않음.
- 검사: `node tests/room-webgl.cjs`, `node tests/room-transition.cjs` 및 기존 퍼즐·입력 회귀 검사.

## 현재 복도 렌더링

- 복도·계단·2층 착지를 하나의 WebGL 공간으로 렌더링. 기존 금속 질감, 형광등, 정전 연출과 B-0 디자인 재사용.
- 화면의 문과 바닥은 렌더링에 사용한 동일한 카메라·삼각형을 기준으로 선택. 기존 이동·대화·방 진입·열쇠·계단 규칙과 저장 형식 유지.
- 기존 DOM 대상은 키보드와 화면 읽기에 유지. WebGL을 사용할 수 없으면 기존 CSS 3D 보기로 표시.
- 첫 방 이름은 `출입 관리실`, 기존 3차시 방은 `기록 보관실`. 지도·문패·위치·대사에 적용. 저장용 내부 ID는 유지.
- `lab-webgl.js` / `lab-webgl.css`. 검사: `node tests/lab-webgl.cjs`, `node tests/lab-navigation-input.cjs`.

## 연구소 이동

- 복도 폭 360 → 540, 높이 410 → 470. 새 아이보리·청록 벽면에 조도를 낮추고 문 조명·발밑 유도등만 남긴 어두운 연구소 분위기.
- 복도 진입 후 앞쪽 안전 차단문이 내려오는 연출. 진입 상태 저장, 이후 방문 때 반복하지 않음.
- B-0는 복도의 실제 좌표에서 이동. 시선 회전·열쇠 획득으로 위치가 바뀌지 않고, 문과 차단벽 너머에 배치되지 않도록 제한.
- 임시 검토 버튼: `차시 이동 (임시)`에서 1~4차시 시작 선택, `차시 끝으로 (임시)`에서 해당 차시 마무리 이동. `원위치로`는 시점과 배율만 초기화.
- 방을 나온 뒤 복도를 직접 이동하고, 문 앞에서 입장 선택. 드래그로 시선 회전, 방향키·WASD·이동 버튼으로 보행.
- 연구소 지도에서 방의 위치 확인 및 문 앞으로 이동. 1층에는 실습실·보관실·기록 보관실·유리 관찰실, 2층에는 중앙관리실만 배치.
- 유리 관찰실 너머의 열쇠 보관함에서 열쇠 획득 → 계단 문 잠금 해제 → 계단을 올라 중앙관리실 진입. 계단 왕복 가능.
- 복도 위치·층·열쇠·열린 계단 문 자동 저장. 기존 4차시 저장은 2층 진입 상태로 호환.
- 보관실·기록 보관실·유리 관찰실의 가로·세로 폭을 780 → 1170, 중앙관리실은 1560 → 2340으로 각각 1.5배 확장. 실습실은 기본 시야를 1.5배 넓히고 배경과 조사 대상을 같은 투영으로 표시. 장치와 B-0 크기는 유지.
- 결말의 태블릿과 마지막 완료 화면에 기존 B-0 얼굴 전체 표시. 태블릿 대사에 맞춘 입 움직임 유지.
- 관련 파일: `lab-navigation-model.js`, `lab-navigation.js`, `lab-navigation.css`. 검사: `node tests/lab-navigation.cjs`.

## 4차시: 끝나지 않는 수업

- 거울 관찰실을 통과한 뒤 복도 탐색과 열쇠 획득을 거쳐 2층 중앙관리실로 진행.
- `?chapter=4`는 기존 진입 권한이 있을 때 재입장. 권한이 없으면 현재 진행에서 도달할 수 있는 1층 복도에서 시작. 차시별 저장 분리, 기존 1~3차시 진행 유지.
- 짙은 남색 패널·청동 프레임·호박색 조명. 기존 세밀한 산업 연구소 질감과 B-0 디자인 유지.
- AXIOM은 ‘예상 오류 없음’을 교육 완료 기준으로 삼아 퇴실을 보류하고 B-0 초기화 시도.
- 원본 기록의 재생 위치와 구간을 직접 조작해 잘린 판정의 앞뒤 맥락 확인. 구간을 보고서에 드래그하거나 버튼으로 제출.
- 자동 관리 단자를 직접 분리해 퇴실 판단과 B-0 제어 회수. 문제 풀이 지원은 남겨 두어도 성공 가능.
- 종료 손잡이를 아래 홈에 유지하고 실제 잠금쇠·문 상태 확인. 성급히 놓아도 앞 단계는 유지.
- B-0는 대상별 관찰 사실만 응답. 정답 순서·목표 연결 강조 없음. 시간 제한·카메라 흔들림 없음.
- 조작 대체: 기록 제출·연결 분리·손잡이 유지 버튼, 키보드 대상 선택과 방향키 둘러보기.
- 결말: 오프닝과 이어지는 공부방에서 소년이 먼저 풀이를 검토하고 B-0에게 부분 검산 요청.
- `chapter4-model.js` / `chapter4.js` / `chapter4.css`, 저장 키 `project-b0-final-v1`.
- 새 이미지의 내장 image_gen 프롬프트와 참조 기록: `assets/chapter4-art-manifest-v1.json`.
- 검사: `node tests/chapter4-flow.cjs`, `node tests/chapter4-input.cjs`, `node tests/chapter-routing.cjs`.

## 이야기와 플레이

- 첫 화면: 깨어난 학생의 눈앞을 가득 채운 B-0 얼굴. 타이틀 메뉴나 공부 영상 없이 즉시 시작.
- 1인칭. 학생 캐릭터는 화면에 나오지 않으며 대사와 속마음만 표시.
- B-0 소개 → 폐쇄된 AI 교육 연구소 확인 → 출구를 모른다는 답변 → 학생의 의심 → 표정에서 실망을 짐작하는 질문 → 출입구 탐색 제안.
- 원래 실습실 배경, B-0 스프라이트, 출입문·안내도·단말기·비상등 디자인 재사용.
- 마우스·터치 드래그로 방을 둘러보고 물건을 누르면 바로 조사. 방향키 탐색과 Tab 물건 선택 지원. 방 전체 버튼 제거.
- 기존 미술과 장치 디자인을 참조한 하나의 연속 equirectangular 배경. WebGL 구면 투영으로 수평 360도 회전, 위아래 18도 시선 이동. 이미지별 벽·바닥 이음새 제거. 자유 보행은 아님.
- 왼쪽 보관장·오른쪽 실습대·오른쪽 관찰창 조사 가능. 비밀번호 쪽지는 계속 B-0의 보관함에서만 발견.
- 상단에 내 위치: 출입 관리실과 현재 바라보는 방향 표시. 처음으로 버튼은 확인 후 진행 초기화.
- 도입 대사의 감정에 맞춰 눈썹 변화·눈 깜빡임·입 모양 애니메이션. 음성 없이 대사 길이에 맞춰 입 움직임 종료.
- 도입과 탐색에 같은 투명 B-0 전신 이미지 사용. 얼굴 확대 상태에서 약 1.8초 동안 실제 전신 위치로 축소. 사각 사진·전신 교차 전환 없음. 동작 줄이기 설정에서는 전환 생략.
- 벽면 안내도에서 관리용 쪽지의 비밀번호로 탈출하는 방법 발견.
- B-0는 자신의 보관함 안을 확인하지 않아 쪽지가 있다는 사실을 모름.
- B-0와 대화 → 보관함 확인 → 쪽지 받기. 쪽지에는 4732가 온전히 적혀 있음.
- 도어락에 4732 입력 → 잠금 해제 → 손잡이를 돌려 탈출.
- 숫자 가림·암호 조합·AI 오독·추가 퀴즈 없음. 탐색 순서 강제 없음.
- 잘못된 번호는 재시도 가능. 쪽지는 소지품과 도어락에서 다시 확인.
- 탈출 후 AXIOM의 B-0 이동 제한 안내와 다음 공간 예고. 다음 공간은 미구현.

## 교육 내용

- AI도 확인하지 않은 정보는 모를 수 있음.
- 모르는 것을 인정하고, 사람과 함께 정보를 확인해 문제 해결.
- B-0가 표정을 보고 실망했는지 질문. 속마음을 정확히 읽는 능력으로 표현하지 않음.
- 실제 AI 호출·얼굴 인식 없이 정해진 게임 규칙으로 구현.
