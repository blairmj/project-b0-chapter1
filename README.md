# PROJECT B-0 · 1차시: 깨어난 실습실

- 대상: 초등학교 5–6학년
- 목표: 단서를 근거로 대상과 행동을 명확하게 지시하고, AI의 실행 결과를 직접 확인
- 플레이: 방 조사 → 지시 조립 → B-0의 이해 확인 → 실행 관찰 → 결과 검증 → 탈출
- 수업 구성: 도입 5분 / 탐색·짝 토의 10분 / 지시·수정 실습 15분 / 정리 10분
- 게임 자체 분량과 40분 수업 시간은 다름. 교사 발문과 짝 토의 포함

[GitHub Pages에서 플레이](https://blairmj.github.io/project-b0-chapter1/)

## 실행

- index.html: 기본 진입점
- lesson1.js: 1차시 상태·대화·지시·저장
- lesson1.css: 세로 UI·스프라이트·장치 상태·이동
- preview-v2.html: 같은 게임의 검증용 진입점
- game.js, style.css, 기존 PNG: 이전 구현 보관, 현재 진입점에서는 사용하지 않음
- 로컬 서버: 이 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000 접속
- 정적 HTML/CSS/JS. 빌드, 서버 API, API 키 불필요
- 실제 생성형 AI 호출 없음. 지시에 대한 반응은 정해진 게임 규칙으로 구현

## 학습 분기

- 단서: 출입문·단말기·안내도 필수, 비상등 비교 조사 선택
- “저거 켜 줘”: B-0가 대상 재질문
- 비상등 켜기: 방만 밝아짐, 문은 잠긴 상태 유지
- 출입문 먼저 열기: 잠금 때문에 실행 불가, 연결 장치 확인 안내
- 단말기 켜기: 단말기 작동·잠금 표시 변경
- 잠금 확인: 출입문을 조사한 후 실제 표시 변화 선택
- 오답: 점수 감점·시간 제한 없이 근거 설명 후 재시도
- 탈출 후 대상+행동, 결과 검증 정리 활동 2개
- 다음 차시: 데이터 복구실 예고. 2–4차시 플레이 미포함

## 2026-10-23 화면 간소화

- 상단 목표 하나, 장면, 한 사람의 대사, 현재 단계의 행동으로 구성.
- 첫 조사 지점은 출입문만 표시. 출입문 → 단말기 → 지시 → 실제 잠금 표시 확인 → 탈출 순서.
- 안내도·비상등은 선택 탐색. 필수 단서는 출입문과 단말기.
- 중복 조사 버튼과 행동 탭 제거. 단서·힌트·기록·소리는 메뉴로 이동.
- 지시는 문장 선택과 B-0의 재확인으로 구성. 모호한 지시와 잘못된 장치 선택에 수정 피드백 제공.
- 학생 왼쪽, B-0 오른쪽. 행동 영역 높이 유지로 클릭 때 장면 크기 변화 방지.
