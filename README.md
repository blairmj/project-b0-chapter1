# PROJECT B-0 · 연구소 탈출

## 4차시: 끝나지 않는 수업

- 거울 관찰실을 통과한 뒤 중앙관리실 앞의 ‘중앙관리실로 들어가기’로 계속 진행.
- 직접 진입: `?chapter=4`. 차시별 저장 분리, 기존 1~3차시 진행 유지.
- 짙은 남색 패널·청동 프레임·호박색 조명. 기존 세밀한 산업 연구소 질감과 B-0 디자인 유지.
- AXIOM은 ‘예상 오류 없음’을 교육 완료 기준으로 삼아 퇴실을 보류하고 B-0 초기화 시도.
- 원본 기록의 재생 위치와 구간을 직접 조작해 잘린 판정의 앞뒤 맥락 확인. 구간을 보고서에 드래그하거나 버튼으로 제출.
- 자동 관리 단자를 직접 분리해 퇴실 판단과 B-0 제어 회수. 문제 풀이 지원은 남겨 두어도 성공 가능.
- 종료 손잡이를 아래 홈에 유지하고 실제 잠금쇠·문 상태 확인. 성급히 놓아도 앞 단계는 유지.
- B-0는 대상별 관찰 사실만 응답. 정답 순서·목표 연결 강조 없음. 시간 제한·카메라 흔들림 없음.
- 조작 대체: 기록 제출·연결 분리·손잡이 유지 버튼, 키보드 대상 선택과 방향키 둘러보기.
- 결말: 오프닝과 이어지는 공부방에서 소년이 먼저 풀이를 검토하고 B-0에게 부분 검산 요청.
- `chapter4-model.js` / `chapter4.js` / `chapter4.css`, 저장 키 `project-b0-final-v1`.
- 새 이미지의 내장 image_gen 프롬프트와 참조 기록: `assets/chapter4-art-manifest-v1.json`.
- 검사: `node tests/chapter4-flow.cjs`, `node tests/chapter4-input.cjs`, `node tests/chapter-routing.cjs`.

## 이야기와 플레이

- 첫 화면: 깨어난 학생의 눈앞을 가득 채운 B-0 얼굴. 타이틀 메뉴나 공부 영상 없이 즉시 시작.
- 1인칭. 학생 캐릭터는 화면에 나오지 않으며 대사와 속마음만 표시.
- B-0 소개 → 폐쇄된 AI 교육 연구소 확인 → 출구를 모른다는 답변 → 학생의 의심 → 표정에서 실망을 짐작하는 질문 → 출입구 탐색 제안.
- 원래 실습실 배경, B-0 스프라이트, 출입문·안내도·단말기·비상등 디자인 재사용.
- 마우스·터치 드래그로 방을 둘러보고 물건을 누르면 바로 조사. 방향키 탐색과 Tab 물건 선택 지원. 방 전체 버튼 제거.
- 기존 미술과 장치 디자인을 참조한 하나의 연속 equirectangular 배경. WebGL 구면 투영으로 수평 360도 회전, 위아래 18도 시선 이동. 이미지별 벽·바닥 이음새 제거. 자유 보행은 아님.
- 왼쪽 보관장·오른쪽 실습대·오른쪽 관찰창 조사 가능. 비밀번호 쪽지는 계속 B-0의 보관함에서만 발견.
- 상단에 내 위치: 교육 실습실과 현재 바라보는 방향 표시. 처음으로 버튼은 확인 후 진행 초기화.
- 도입 대사의 감정에 맞춰 눈썹 변화·눈 깜빡임·입 모양 애니메이션. 음성 없이 대사 길이에 맞춰 입 움직임 종료.
- 도입과 탐색에 같은 투명 B-0 전신 이미지 사용. 얼굴 확대 상태에서 약 1.8초 동안 실제 전신 위치로 축소. 사각 사진·전신 교차 전환 없음. 동작 줄이기 설정에서는 전환 생략.
- 벽면 안내도에서 관리용 쪽지의 비밀번호로 탈출하는 방법 발견.
- B-0는 자신의 보관함 안을 확인하지 않아 쪽지가 있다는 사실을 모름.
- B-0와 대화 → 보관함 확인 → 쪽지 받기. 쪽지에는 4732가 온전히 적혀 있음.
- 도어락에 4732 입력 → 잠금 해제 → 손잡이를 돌려 탈출.
- 숫자 가림·암호 조합·AI 오독·추가 퀴즈 없음. 탐색 순서 강제 없음.
- 잘못된 번호는 재시도 가능. 쪽지는 소지품과 도어락에서 다시 확인.
- 탈출 후 AXIOM의 B-0 이동 제한 안내와 다음 공간 예고. 다음 공간은 미구현.

## 교육 내용

- AI도 확인하지 않은 정보는 모를 수 있음.
- 모르는 것을 인정하고, 사람과 함께 정보를 확인해 문제 해결.
- B-0가 표정을 보고 실망했는지 질문. 속마음을 정확히 읽는 능력으로 표현하지 않음.
- 실제 AI 호출·얼굴 인식 없이 정해진 게임 규칙으로 구현.
