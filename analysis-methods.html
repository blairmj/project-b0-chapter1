무엇을, 어떻게 읽을까?

재미, 스스로 느끼는 능력, 상황에서의 판단을 구분하는 사후 평가입니다.

이 설문은 B-0의 교육 목표에 맞춰 만든 시범 도구(b0-post-1.0)입니다. 표준화되거나 타당도가 검증된 척도가 아닙니다. 사후 설문만으로 학습 향상이나 게임의 인과 효과를 주장하지 않습니다.

01 · 수집 절차

  1. 교사가 목적·참여 방식·보관 기간·전달 경로를 안내합니다. 연구에 사용하는 경우 필요한 학교·기관 절차와 보호자·학생 참여 안내를 별도로 마련합니다. 이 페이지는 동의서를 대신하지 않습니다.
  2. 게임 직후 학생이 모험 돌아보기에 답합니다. 정답이나 친구의 답을 먼저 보여 주지 않습니다. 일부만 플레이한 경우 실제 범위를 고르게 합니다.
  3. 이름 대신 교사가 정한 참여 코드와 모둠 코드만 사용합니다. 코드를 적지 않아도 응답할 수 있습니다. 모든 문항은 건너뛸 수 있습니다.
  4. 학생이 마지막 단계에서 JSON 응답 파일을 저장하고 교사가 정한 경로로 전달합니다. 파일이 자동 전송되거나 중앙 서버에 모이지 않습니다.
  5. 분석 페이지에서 여러 파일을 함께 불러옵니다. 같은 응답 ID는 최신 저장 시각의 파일을 유지합니다. 같은 참여 코드라도 ID가 다르면 자동 병합하지 않으므로 원본을 검토합니다.
  6. 미리보기 응답은 기본적으로 제외합니다. 학급·모둠과 플레이 범위를 확인한 뒤 CSV·분석 묶음을 저장합니다. 공용 기기에서는 파일 전달을 확인하고 ‘다음 참여자 시작’을 눌러 이전 작성 내용을 새 응답으로 바꿉니다.

학생 페이지는 해당 기기에 작성 중인 답변 1건을 자동 저장합니다. 분석 페이지는 불러온 자료를 탭 안에서만 처리합니다. 서술형에 개인정보가 들어간 경우 공유하기 전에 식별 정보를 가려 주세요.

02 · 문항과 변인

핵심 자기평가는 ‘게임을 해 본 지금’의 상태를 묻습니다. ‘향상되었다’는 회고식 변화 문항으로 대체하지 않습니다.

문항내용해석
V1~V3다른 단서와 비교 / 설명과 결과의 차이 확인 / 추가 정보 찾기근거 확인에 대한 자기평가
I1~I3대상 / 행동 / 유지·종료 조건 명시구체적 지시에 대한 자기평가
R1~R3오류 단계 나누기 / 필요한 도움 요청 / 방법 수정 후 재시도점검과 재시도에 대한 자기평가
A1~A3사람·AI 역할 분담 / 결과 확인 / 최종 선택역할 분담과 자기 판단에 대한 자기평가
S1~S4도서관 최신 정보 / 손잡이 명령 / 단계별 풀이 / 발표 자료 확인각 문항군과 연결된 상황 판단. 실제 수행 검사와는 구분
E1~E4재미 / 재도전 의향 / 조작 이해 / 글 이해문항별 플레이 경험. 서로 합산하지 않음
O1~O3직접 확인한 근거 / 방법을 바꾼 전후 / 어려움과 개선 의견경험의 구체성과 개선 단서

객관식은 S1=B, S2=C, S3=A, S4=D를 정답으로 코딩합니다. 정답과 이유·모든 보기는 분석 화면에서 확인할 수 있습니다. 응답 파일의 문항 ID는 survey-model.js의 동일 버전 문항에 대응합니다.

학년·AI 사용 경험·플레이 범위·모둠 코드는 보조 정보입니다. 성별·생년월일·연락처는 수집하지 않습니다. 코드가 개별 학생과 연결되어 있다면 완전한 익명 자료로 표현하지 않습니다.

03 · 수치 분석과 결측 처리

  1. 자료 점검: 응답 ID·설문 버전·값의 범위를 검사합니다. 지원하지 않는 버전이나 잘못된 값이 들어 있는 파일은 불러오지 않고 오류를 표시합니다. 무응답이 많거나 반복 코드인 자료는 확인하되 임의로 제거하지 않습니다. 빠르게 답했다는 이유만으로 자동 배제하지 않습니다.
  2. 설문 응답률: 현재 분석 조건에 해당하는 대상 인원을 알고 있을 때만 입력합니다. 고유 응답 수 ÷ 대상 인원으로 산출합니다. 파일을 받지 못한 학생의 특성은 이 페이지에서 알 수 없습니다.
  3. 문항별 기술통계: 1~5점의 빈도, 평균, 표본 표준편차(SD), 중앙값, 4~5점 비율과 유효 n·무응답 수를 함께 보고합니다. SD는 n−1로 나누며, n<2이면 표시하지 않습니다. 단일 순서형 문항의 평균은 분포·중앙값과 함께 해석합니다.
  4. 문항군별 요약: 3문항 중 2개 이상 답한 경우에만 그 학생의 응답 평균을 구합니다. 이후 개인 평균들을 요약합니다. 이 기준은 이 시범 도구의 사전 분석 규칙이며 검증된 척도 지침이 아닙니다. 응답 1개 이하인 학생은 해당 문항군의 산출 불가 수에 포함합니다.
  5. 상황 문제: 정답 1점, 오답·모르겠어요 0점, 건너뛴 문항은 결측입니다. 문항 정답률의 분모는 ‘모르겠어요’를 포함한 실제 응답 수입니다. 4문항 합계는 모두 응답한 학생에게만 계산합니다. 모르겠어요와 오답 수는 따로 제시합니다.
  6. 분리 보고: 자기평가, 상황 문제, 재미·사용성을 합친 전체 총점을 만들지 않습니다. 서술형도 선택형 점수에 더하지 않습니다. 모든 빈칸은 0점·중립 응답으로 바꾸거나 평균 대체하지 않습니다.
예: V1=4, V2=빈칸, V3=5 → 개인 근거 확인 평균 4.5
V1=4, V2=빈칸, V3=빈칸 → 문항군 평균 산출 불가
S1=정답, S2=모르겠어요, S3=빈칸, S4=오답 → 문항별 분석에 포함, 4문항 합계는 제외

학급·플레이 범위를 섞기 전에 수업 조건이 같은지 확인합니다. 사전 AI 경험·교사 도움·읽기 수준·기기 경험은 해석에 영향을 줄 수 있습니다. 소집단 비교를 전체 학생의 일반적 특성으로 확대하지 않습니다.

04 · 서술형 코딩

O1과 O2는 0~2점으로 사람이 채점합니다. 빈 답은 0점이 아니라 ‘무응답·미채점’으로 남깁니다. O3는 점수를 붙이지 않고 개선 주제로 분류합니다.

문항0점1점2점
O1 근거 확인관련 없는 설명, 또는 근거 없이 AI를 그대로 따랐다고만 설명확인·비교했다는 행동은 있지만 무엇을 비교하고 판단했는지 불분명구체적 단서와 안내를 대조하고 그에 따른 판단을 설명
O2 방법 수정관련 없는 설명, 또는 수정 없이 반복했다고만 설명부탁·방법을 바꿨다고 하나 전후의 차이나 결과가 불분명바꾸기 전후의 지시·방법과 그 결과를 구체적으로 설명

O1 2점 예시: “지도에는 출구였는데 문을 열어 보니 벽이어서, 지도가 지금과 다르다고 생각했다.”
O2 2점 예시: “내려 달라고만 했더니 놓아서, 내가 놓으라고 할 때까지 잡아 달라고 바꿨고 문을 열었다.”

예시는 채점자 참고용이며 학생에게 답하기 전에 제시하지 않습니다. 다른 타당한 장면도 같은 기준으로 채점합니다. 근거가 부족한 답변을 실제 능력의 부재로 단정하지 않습니다.

O3의 시작 주제는 ‘조작·이동’, ‘읽기·대화’, ‘힌트·난이도’, ‘이야기·캐릭터’, ‘기타’로 둘 수 있습니다. 답변을 읽으며 새 주제를 추가하고 코드북에 기록합니다. 하나의 답변에 여러 주제를 붙일 수 있어 주제별 비율의 합이 100%를 넘을 수 있습니다.

연구용이라면 두 채점자가 일부 답변을 독립적으로 코딩한 뒤 기준을 조정하고, 일치율과 불일치 사례를 기록합니다. 충분한 자료가 있으면 순서형 점수의 가중 Cohen’s κ 등 채점자 간 신뢰도를 별도 통계 도구로 검토합니다. 이 대시보드는 신뢰도를 자동 계산하지 않습니다. 최종 점수·주제·채점 메모는 코딩 CSV와 분석 묶음에 저장됩니다.

05 · 결과를 함께 해석하기

  • 자기평가가 높고, 관련 상황 문제를 풀며, 서술형에서 구체적 근거를 설명함 → 여러 자료가 같은 방향을 보이는지 검토합니다.
  • 자기평가는 높지만 상황 문제나 근거 설명이 어려움 → 다음 수업에서 직접 시연하거나 다른 상황으로 확인합니다.
  • 상황 문제는 맞지만 자기평가가 낮음 → 자신감과 판단 능력이 다를 가능성을 검토합니다.
  • 조작·글 이해가 어렵고 무응답이 많음 → 접근·읽기 부담을 먼저 살펴봅니다.

‘높다·낮다’는 검증된 절단점으로 자동 분류하지 않습니다. 대시보드는 관찰값을 그대로 보여 줍니다. 모둠 간 점수 차이가 게임 효과인지, 기존 경험과 수업 조건의 차이인지는 사후 자료만으로 분리할 수 없습니다.

보고 문장 예시 틀:
“분석 대상 n=__명 중 근거 확인 문항군을 산출할 수 있는 __명의 평균은 __(SD=__)이었다. S1 정답률은 __%(__/__명)이며 무응답은 __명이었다. 서술형에서는 __와 같은 근거 비교 사례가 나타났다. 사후 조사이므로 학습 향상이나 인과 효과로 해석하지 않았다.”

거울 관찰실과 반사판 공략 기록

b0-post-1.1은 공부 방법·시간의 자료 해석과 후속 시험 조건을 묻는 상황 문항을 포함합니다. 이전 b0-post-1.0 파일은 계속 읽을 수 있으나 분석 화면에서 설문 버전별로 구분합니다. 문항이 달라진 두 버전의 상황 판단 점수를 하나의 집단으로 합치지 않습니다. 작성 중이던 1.0 응답도 기존 문항으로 이어집니다.

거울 관찰실을 플레이한 기기에서는 익명 플레이 ID, 시험 횟수, 관찰한 장치 수, 시험 전 예상 횟수, 한 장치·여러 장치를 바꾼 시험 횟수, 휴대용 반사판 획득 여부, 보스전의 반사판 시험과 연결 해제 여부가 답변 JSON과 원자료 CSV에 포함됩니다. 전체 대화, 사용자 호칭, 별도 개인정보는 포함하지 않습니다. 답변 파일의 전달 방식은 기존과 같습니다.

같은 플레이 ID의 여러 설문은 같은 수행을 공유할 수 있습니다. 독립된 수행 사례로 중복 합산하지 말고, 참여·수업 절차와 함께 확인하세요. 기기 변경이나 게임 초기화 후에는 이 자동 연결이 이어지지 않습니다. 기록이 없다는 이유로 수행 점수를 0점 처리하지 않습니다.

시험 횟수가 적으면 우연히 맞혔거나 처음부터 원리를 이해했을 수 있고, 많으면 탐색·조작 어려움·의도적인 비교일 수 있습니다. 한 장치씩 바꾼 횟수도 이해의 자동 점수가 아닙니다. 자기평가·새 상황에서의 판단·구체적 행동 기록을 함께 해석합니다. 이 자료만으로 학습 향상을 단정하지 않습니다.

06 · 학습 효과까지 확인하려면

현재 구현은 사후 평가입니다. 향상을 확인하려면 같은 참여 코드로 연결할 수 있는 사전·사후 자료와 실제 수행 과제를 별도로 설계해야 합니다. 사후 점수에서 가상의 사전 점수를 빼지 않습니다.

  1. 먼저 전문가 검토와 학생 대상 문항 이해 확인을 거쳐 시범 문항의 내용과 표현을 다듬습니다. 충분한 자료에서 문항군 구조와 신뢰도·타당도를 검토하기 전에는 표준 척도로 사용하지 않습니다.
  2. 사전·사후에 동일한 능력을 묻되, 상황 문제는 평행한 문항으로 구성해 답 기억의 영향을 줄입니다. 대상·행동·종료 조건 선택하기와 오류 찾기 같은 수행 자료를 함께 수집합니다.
  3. 가능하면 수업 조건이 유사한 비교집단과 사전 측정치를 확보합니다. 무작위 배정 여부, 교사 도움, 플레이 시간·완료 범위를 기록합니다.
  4. 분석 방법과 제외·결측 규칙을 사전에 정합니다. 자기평가 점수의 변화는 자료 조건에 맞는 대응 분석, 문항별 정오 변화는 대응 이진 자료 분석 등을 검토하고 효과크기·불확실성을 함께 보고합니다. 비교집단이 있으면 사전 차이와 집단·시점 구조를 반영합니다. 구체적 검정은 설계와 표본을 확인한 뒤 선택합니다.

비교집단 없이 관찰된 사전·사후 변화도 연습 효과나 다른 수업 경험을 배제하지 못합니다. 현재 대시보드는 사전·사후 검정, 인과 추론, 자동 유의성 판정을 수행하지 않습니다.

참고 자료와 도구의 범위
